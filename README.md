# 🎬 SyncDrop (异地 P2P 原画影音同步播放器)

> 纯前端、无服务器（Serverless）、零成本的异地媒体同步解决方案。基于 WebRTC 技术，无需公网 IP 和独立服务器，完美支持 iOS / Android / 平板 / 电脑跨平台联机观影。

---

## ✨ 核心特性

- 🚀 **完全无服务器 (100% Serverless)**：不需要购买域名，不需要公网 IP，不耗费服务器流量与存储。
- 📦 **单方选片，原画直传**：只需要一方拥有本地视频/音频文件，后台自动通过 P2P 隧道切片分发至对方设备，对方无需提前下载。
- 💎 **弱网画质绝不失真**：摒弃传统“动态压码率推流”的模糊体验，采用**原始数据分块直传**，网络再差也能保证 100% 原始画质，缓冲后本地流畅播放不掉帧。
- 📱 **全平台开箱即用**：针对 iOS Safari、Android Chrome、PC 浏览器专门做过移动端适配与防全屏锁死优化。
- 🔒 **端到端私密安全**：媒体数据仅在两台设备之间直连传输，中间不经过任何第三方云存储服务器，隐私零泄露。

---

## 🛠️ 技术栈

- **网络打洞与通信**：[PeerJS](https://peerjs.com/) (WebRTC DataChannel + 公共 STUN)
- **底层流处理**：HTML5 File API / FileReader (二进制分块及背压控制)
- **播放引擎**：HTML5 Audio/Video API (Blob Object URL)
- **托管托管**：[Cloudflare Pages](https://pages.cloudflare.com/) (免费静态托管，自带 SSL/HTTPS)

## 🚀 部署指南 (一分钟上线)

### 方法一：使用 Cloudflare Pages 直接上传（最推荐）

1. 将本仓库下载到本地解压，确保文件夹内含有 `index.html`。
2. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)。
3. 导航至 **Workers 和 Pages** -> **创建应用程序** -> **Pages** -> 选择 **直接上传 (Direct Upload)**。
4. 输入你的项目名称，将包含 `index.html` 的文件夹拖动上传，点击 **部署站点**。
5. 部署完成后，你将获得一个免费的专属二级域名（如 `https://your-sync-player.pages.dev`）。

### 方法二：本地直接运行
无需搭建任何 Web 服务器，直接双击使用 Chrome / Edge 浏览器打开 `index.html` 即可运行。

## 📖 使用步骤

1. **建立连接**：
   - 双方使用手机或电脑打开部署好的网页。
   - 任意一方复制页面上显示的“连接码”发送给对方。
   - 另一方将连接码粘贴至输入框，点击 **“连接对方”**（显示绿色成功提示即代表直连通道建立）。
2. **选择并传输媒体**：
   - 发片方点击 **“选择文件”**，挑选本地任意视频或音频。
   - 页面会自动展示切片传输进度条；传输完成后，双方即可同时加载原画。
3. **同步观影**：
   - 任一方进行播放、暂停、进度条拖拽（Seek），另一方将以毫秒级延迟实时同步。

## ⚠️ 移动端注意事项

- **苹果 iOS (iPhone/iPad)**：
  - 由于 iOS Safari 的后台挂起机制，**在传输文件过程中请保持页面在前台并长亮屏幕**，切入微信后台可能会导致传输中断。
  - 受浏览器自动播放安全策略限制，接收端加载完成后，建议**手动点击一次屏幕播放**以解除音频静音锁。
- **文件体积建议**：
  - 手机端浏览器分配的内存有限，建议传输日常 **1080P/720P（500MB ~ 1.5GB）** 的视频。过大的单个巨型文件（如 20GB 的 4K 蓝光原盘）可能导致手机浏览器内存耗尽闪退。
